# 中国各地市公共资源交易系统承建公司统计

本仓库用于收集、整理中国各地市（含省本级、地市）**公共资源交易系统**的承建 / 建设厂商信息，便于检索与对比。

## 统计范围（含配套延伸）

本仓库以各地市（含省本级）**公共资源交易系统**承建 / 建设 / 运维厂商为主；同时纳入与交易平台紧密配套的**公共资源交易配套延伸领域**。

### 明确纳入：网上中介服务超市 / 中介超市信息化系统

**在范围内**（广东及一般情形）：

- 网上中介服务超市 / 中介超市信息化系统的**平台建设、升级、运维、运营**（即超市系统本身的信息化承建与运维运营合同）
- 省本级与各地市超市平台；广东省级入口为粤公平中介超市：<https://ygp.gdzwfw.gov.cn/zjfwcs/gd-zjcs-pub/>
- `system_url`：省本级可用上述省级超市门户；地市可用粤公平地市门户或当地超市/政务入口 URL

**明确不在本扩展范围内**：

- 企业在中介超市上**中选承接中介服务业务**的个别中选记录（例如某公司经中介超市中选珠海「一网统管」等服务项目）——那是超市上的业务成交，**不是**超市平台承建商，除非该项目本身就是超市系统建设/升级/运维/运营

建议在 `notes` 中以 `[中介超市]` 开头，便于分析过滤。


## 数据字段

见 `data/contractors.csv`，核心字段：

| 字段 | 说明 |
|------|------|
| province | 省 / 自治区 / 直辖市 |
| city | 地市或「省本级」 |
| system_name | 系统或平台名称 |
| system_url | 官网或入口 URL |
| contractor | 承建 / 建设公司 |
| contractor_uscc | 统一社会信用代码（如有） |
| contract_year | 建设或中标年份（如有） |
| source | 信息来源（公告、官网、新闻等） |
| notes | 备注 |
| updated_at | 更新日期（YYYY-MM-DD） |

## 使用方式

1. 在 `data/contractors.csv` 追加一行记录。
2. 尽量注明 `source`，便于复核。
3. 同一地市若有多期建设或更换厂商，保留多行并在 `notes` 说明。

## 广东数据源：粤公平

广东省公共资源交易平台（**粤公平**）是广东省级统一门户，汇聚省级与各地市交易公开、交易系统入口与政策信息：

- 省级门户：<https://ygp.gdzwfw.gov.cn/ggzy-portal/index.html#/44/index>
- 地市门户路由：`#/{行政区划代码}/index`（例：广州 `440100`、深圳 `440300`、江门 `440700`）
- 主办：广东省人民政府办公厅；承办：广东省政务服务和数据管理局；门户页脚技术支持：**数字广东网络建设有限公司**

核验广东承建/运维信息时，应优先对照粤公平「交易公开」及各地市交易系统入口；政府采购类结果亦常同步至国家平台 / 广东政府采购网。门户为前端 SPA，公告检索接口需签名，自动化抓取受限时可改用国家公共资源交易平台广东镜像或地市财政网交叉核验。

详见 `DATA.md` 广东专节。
